01

INPUT PARSING parseInput()

Every keypress mutates a string; parseInput() sanitizes that raw display value into a real Number before arithmetic ever touches it — tolerating trailing dots, signs, and exponent notation so partial input never corrupts a computation.

parseInput("-42.") → -42
02

EVENT HANDLING addEventListener()

A single delegated click listener on the keypad routes every button by data-action — no per-button wiring. The equals button fires handleEquals(), which evaluates the pending operation, prints the tape line, and arms repeat-equals.

keypad.addEventListener("click", route)
03

ERROR HANDLING try / catch

Division by zero, the undefined 0 ÷ 0, and overflow all throw guarded error objects. The LCD reports the fault, the status lamp flips to ERR, the state machine locks out operators — and the next digit performs a clean recovery.

5 ÷ 0 = → ERR: DIVIDE BY ZERO
04

KEYBOARD INPUT keydown

A global keydown listener mirrors the full keypad: digits, operators, Enter, Escape, Backspace and %. Each physical key flashes its on-screen twin, so you can watch the DOM event land in real time while the last-key monitor reports the raw e.key.

Enter ⇒ = · Esc ⇒ AC · ⌫ ⇒ DEL
